# Security

This repository documents a cybersecurity networking project developed in a controlled virtual laboratory environment.

## Scope

The project is intended for educational and laboratory purposes.

## Sensitive Information

The repository must not contain:

- Passwords or credentials
- Private keys
- VPN secrets
- API tokens
- License files
- Confidential institutional information
- Real patient or personal data

All configurations and demonstrations should use laboratory or anonymized information.

## Reporting a Security Issue

If you identify a security issue in the repository, please describe it clearly and responsibly before publicly disclosing sensitive details.
