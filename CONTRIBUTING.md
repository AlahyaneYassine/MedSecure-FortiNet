# Contributing

Contributions, suggestions and improvements are welcome.

When contributing to this project:

- Keep documentation clear and technically accurate.
- Do not upload passwords, private keys, certificates or other sensitive information.
- Do not upload confidential documents or data.
- Clearly describe any proposed configuration or architectural change.
- Test configuration changes in a controlled laboratory environment before documenting them.

For major changes, please describe the proposed modification and its purpose before submitting it.
