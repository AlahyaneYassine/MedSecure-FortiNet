# FortiAnalyzer

## Overview

FortiAnalyzer is used as the centralized logging and monitoring platform for the MedSecure-FortiNet infrastructure.

It collects and analyzes security and traffic logs generated by the FortiGate devices.

## Role in the Architecture

FortiAnalyzer provides centralized visibility into the security events generated by the network infrastructure.

Main functions:

* Centralized log collection
* Traffic monitoring
* Security event analysis
* VPN activity monitoring
* Firewall event monitoring
* Security investigation support

The centralized logging architecture makes it possible to correlate and analyze events generated by the different FortiGate devices.

## Monitored Events

The platform can provide visibility into events such as:

* Firewall traffic
* Accepted and denied connections
* VPN activity
* Authentication events
* Security events
* Network activity

## Security Monitoring

Centralized logging helps with:

* Security event investigation
* Network troubleshooting
* Detection of abnormal activity
* Audit and traceability
* Incident analysis

FortiAnalyzer therefore complements the preventive controls implemented through FortiGate by providing centralized visibility into network activity.
