# FGT_CLINIQUE

## Overview

`FGT_CLINIQUE` is the main FortiGate firewall of the MediClinic infrastructure.

It provides network segmentation, traffic control, secure remote access, site-to-site connectivity and security logging.

## Role in the Architecture

The firewall is positioned at the core of the clinic infrastructure and controls communication between the different network zones.

Main functions:

* VLAN segmentation
* Inter-VLAN traffic control
* Internet connectivity
* Firewall policy enforcement
* Site-to-site IPsec VPN
* SSL-VPN remote access
* Security logging
* FortiAnalyzer integration

## Network Interfaces

| Interface | Role           | Network           |
| --------- | -------------- | ----------------- |
| `port1`   | WAN / Internet | `10.0.137.0/24`   |
| `port2`   | VLAN trunk     | Internal VLANs    |
| `port3`   | IPsec transit  | `172.16.255.0/30` |

## VLANs

| VLAN    | Network           | Gateway        | Purpose        |
| ------- | ----------------- | -------------- | -------------- |
| VLAN 10 | `192.168.10.0/24` | `192.168.10.1` | Administration |
| VLAN 20 | `192.168.20.0/24` | `192.168.20.1` | Medical Staff  |
| VLAN 40 | `192.168.40.0/24` | `192.168.40.1` | Servers        |

The segmentation limits direct communication between users, medical staff and server resources.

## Site-to-Site IPsec

`FGT_CLINIQUE` establishes a site-to-site IPsec VPN with `FGT_LABO`.

### Clinic Side

```text
Transit interface: 172.16.255.1/30
Protected network: 192.168.40.0/24
```

### Laboratory Side

```text
Transit interface: 172.16.255.2/30
Protected network: 192.168.50.0/24
```

The tunnel allows controlled communication between the clinic server network and the remote laboratory network.

## SSL-VPN

SSL-VPN provides secure remote access for authorized medical staff.

### Configuration

```text
User group: GRP_SSLVPN_MEDECINS
VPN pool: 10.10.10.0/24
```

Remote users are granted access through firewall policies according to the security architecture.

## Firewall Security

Firewall policies are used to control communication between:

* Internal VLANs
* Server resources
* Remote laboratory
* SSL-VPN users
* Internet-facing services

Only required traffic is intended to be allowed between security zones.

## Logging and Monitoring

Security and traffic events generated by the FortiGate are forwarded to **FortiAnalyzer** for centralized logging and analysis.

This provides visibility into:

* Traffic activity
* Firewall events
* VPN activity
* Security events
* Authentication activity

## Validation

The configuration was validated through:

* VLAN connectivity tests
* Inter-network communication tests
* IPsec tunnel verification
* Remote-access verification
* Firewall policy testing
* FortiAnalyzer log collection

## Security Note

This repository intentionally does not contain:

* Administrator passwords
* VPN pre-shared keys
* Private keys
* Certificates containing sensitive material
* API tokens
* License files
* Real patient data
* Other confidential credentials

The repository documents the architecture and implementation of the educational laboratory without exposing sensitive configuration data.
