# FortiAnalyzer

FortiAnalyzer is used in the project for centralized security logging and monitoring.

## Objectives

- Centralize FortiGate security logs
- Monitor network and security events
- Facilitate security analysis
- Provide traceability of network activity

## Log Monitoring

FortiGate logs are forwarded to FortiAnalyzer for centralized analysis.

![FortiAnalyzer Logs](../docs/screenshots/fortianalyzer-logs.png)

## Validation

Log collection was verified through the FortiAnalyzer interface in the PNETLab environment.
