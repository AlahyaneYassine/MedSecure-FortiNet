# FGT_CLINIQUE

Configuration documentation for the FortiGate protecting the main clinic infrastructure.

This device provides:

- Network segmentation
- Inter-VLAN security policies
- Internet connectivity
- Site-to-site IPsec VPN
- SSL-VPN remote access
- Security logging and monitoring

Detailed configuration files will be documented in separate sections while excluding credentials, private keys, VPN secrets and other sensitive information.
